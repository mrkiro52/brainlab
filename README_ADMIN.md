# BrainLab Admin Panel

Полнофункциональная админ-панель для управления контентом сайта BrainLab.

## 🚀 Быстрый старт

### Требования
- Node.js 14+
- npm или yarn

### 1️⃣ Запуск Backend

```bash
cd backend
npm install
npm start
```

Backend будет работать на `http://localhost:3001`

### 2️⃣ Запуск Frontend

В новом терминале:

```bash
cd frontend
npm install
npm run dev
```

Frontend будет доступен на `http://localhost:3000`

## 📝 Первый вход

1. Откройте `http://localhost:3000`
2. Нажмите "Setup admin"
3. Создайте учетную запись администратора
4. Войдите в систему

## 🎯 Функциональность

- ✅ Управление исследованиями
- ✅ Управление публикациями  
- ✅ Управление курсами
- ✅ Управление командой (с фото из URL)
- ✅ Управление проектами
- ✅ Управление блогом

Каждый раздел поддерживает:
- **Создание** новых элементов
- **Редактирование** существующих
- **Удаление** ненужных элементов

## 🔒 Безопасность

- JWT-токены для аутентификации
- Bcrypt хеширование паролей
- Защита всех операций редактирования

## 📁 Структура проекта

```
backend/
  ├── server.js           # Главный сервер
  ├── middleware/auth.js  # JWT аутентификация
  ├── routes/             # API маршруты
  ├── controllers/        # Бизнес-логика

  ├── src/
  │   ├── admin/          # Компоненты админ-панели
```

## 🗄️ База данных

Данные хранятся в JSON файлах в папке `backend/data/`:
- Каждый тип контента имеет свой файл
- Автоматически создаются при первом запуске
- Переносятся вместе с приложением на сервер

## 🔧 Переменные окружения

**Backend** (.env):
```
PORT=3001
JWT_SECRET=ваш-секретный-ключ-измените-в-продакшене
NODE_ENV=development
```

## 📚 API Documentation

### Authentication
- `POST /api/auth/setup` - Создание админа (первый раз)
- `POST /api/auth/login` - Вход админа

### CRUD Operations
Для каждого типа (research, publications, courses, team, projects, blog):

```
GET    /api/{type}        - Получить все элементы
GET    /api/{type}/:id    - Получить один элемент
POST   /api/{type}        - Создать новый (требует токен)
PUT    /api/{type}/:id    - Обновить (требует токен)
DELETE /api/{type}/:id    - Удалить (требует токен)
```

## 🚨 Важно для продакшена

1. **Измените JWT_SECRET** в backend/.env
2. **Используйте HTTPS** для всех запросов
3. **Ограничьте CORS** в backend/server.js
4. **Используйте переменные окружения** для чувствительных данных
5. **Регулярно делайте резервные копии** JSON файлов

## 🐛 Решение проблем

| Проблема | Решение |
|----------|--------|
| Порт занят | Измените PORT в .env (backend) |
| CORS ошибки | Проверьте origins в server.js |
| Данные не сохраняются | Проверьте права на папку backend/data |
| Не работает логин | Убедитесь что backend запущен на 3001 |
